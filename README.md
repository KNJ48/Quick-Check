\# 科学技術部 ゲーム認証管理システム



学校の科学技術部のゲーム発表会用に作成した、

QRコード認証・プレイヤー管理システムです。



\## 主な機能



\- 管理者ログイン

\- QRコード自動生成

\- 先着1人限定認証

\- QRコード15分有効

\- プレイヤーID連番発行

\- プレイヤーセッション管理

\- 5秒ごとのハートビート

\- 受付PCの3秒ごとのハートビート

\- プレイヤー個別停止

\- 全員停止

\- 昼休み終了時刻による自動停止

\- 管理者用ゲーム画面

\- GitHub Pagesのiframe表示



\## 必要な環境変数



ADMIN\_PASSWORD



管理者ログイン用パスワード。



SECRET\_KEY



Flask用の秘密鍵。



32文字以上の推測困難な値を設定してください。
